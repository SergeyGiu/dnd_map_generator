Текстурпаки
Они лежат внутри папки image. Внутри каждого текстур пака одинаковое расположение папок
Базовый текстурпак - base. В нём есть всё.
Если желаете использовать особенный текстур пак, просто добавляешь папку, а внутри необходимую подпапку.
Если в кастомном текстур паке не находится файл, тогда система обращается к базому паку.
Таким образом получится смесь паков.
